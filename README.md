# 헌금계수 (웹 버전)

교회 헌금 계수 · 지출 입력 · 보고서 인쇄용 단일 페이지 앱입니다.

- 이 폴더에는 **교회 장부 자료·이름·금액이 들어 있지 않습니다.** 계정 목록(일반적인 교회 회계 항목 이름)과 화면만 있습니다.
- 처음 열면 재정부에서 받은 *교회 자료 파일*(.json)을 불러와야 합니다. 불러온 자료와 입력한 기록은 그 기기의 브라우저에만 저장되며 서버로 전송되지 않습니다.
- `?demo` 를 붙이면 가상 이름(교인1…)으로 된 예시를 볼 수 있습니다.
- 인터넷 없이도 동작하도록 서비스 워커(sw.js)가 파일을 캐시합니다.
